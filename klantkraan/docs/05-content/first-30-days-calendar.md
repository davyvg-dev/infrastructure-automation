## Workflow (Claude-assisted pipeline)

1. **Idea sourcing**: Perplexity Pro for trends + Installatie.nl/Cobouw RSS via n8n.
2. **Draft**: Claude API (Sonnet for drafts, Opus for cornerstone blogs).
3. **Fact-check + Dutch tone pass**: Claude with the "Dutch direct, no fluff" style guide in system prompt.
4. **Visuals**: Canva Pro for carousels, Excalidraw for diagrams, Loom for screen-recs.
5. **Schedule**: Buffer Essentials for LinkedIn + YouTube.
6. **Distribute**: posts auto-publish; founder responds to DMs in <15 min during business hours.
