# Client Dashboard Spec

> Per-client report page hosted on Cloudflare Pages at `klantkraan.nl/r/{slug}`. Public URL with unguessable slug + signed cookie. Mobile-first.

## What the client sees

Single Astro page, no auth (slug = secret), refreshes on load via edge fetch to n8n.

### Hero strip
- Bedrijfsnaam + logo
- Week-van: "Week 19 — 8 mei t/m 14 mei 2026"
- Tagline: "Powered by Klantkraan"

### Stat tiles (5 in a 2+3 grid on mobile)

| Tile | What | Source |
|---|---|---|
| 1 | AI-opgenomen calls deze week | `calls` where `answered_by='ai'` |
| 2 | Gemiste klanten teruggewonnen | `missed_call_recoveries` where SMS led to booking |
| 3 | Reviews gevraagd deze week | `reviews` where `requested=true` |
| 4 | Reviews ontvangen deze week | `reviews` where `received=true` |
| 5 | Nieuwe boekingen deze week | `bookings` where `ts >= week_start` |

### Recent calls list (laatste 10)
For each: timestamp, intent badge, caller phone (last 4 visible), 30-sec audio-snippet player, transcript preview (truncated).

### Review wall (latest 5)
Stars + reviewer name + first 80 chars + link to full Google review.

### CTA strip
- "Vraag aan Klantkraan?" → WhatsApp link to founder.

## Data model (Neon Postgres)

```sql
CREATE TABLE clients (
  id           UUID PRIMARY KEY,
  name         TEXT NOT NULL,
  slug         TEXT UNIQUE NOT NULL,
  tier         TEXT CHECK (tier IN ('lite','pro','max')),
  created_at   TIMESTAMPTZ DEFAULT now()
);

CREATE TABLE calls (
  id            UUID PRIMARY KEY,
  client_id     UUID REFERENCES clients(id),
  ts            TIMESTAMPTZ NOT NULL,
  direction     TEXT CHECK (direction IN ('inbound','outbound')),
  answered_by   TEXT CHECK (answered_by IN ('ai','human','none')),
  duration_s    INTEGER,
  intent        TEXT,  -- SPOED|NIEUW_WERK|BESTAANDE_KLANT|LEVERANCIER|SPAM
  recovered     BOOLEAN DEFAULT false,
  audio_url     TEXT,
  transcript    TEXT,
  caller_e164   TEXT,
  summary       TEXT
);

CREATE TABLE sms_sent (
  id            UUID PRIMARY KEY,
  client_id     UUID REFERENCES clients(id),
  ts            TIMESTAMPTZ DEFAULT now(),
  type          TEXT,  -- missed_call_back|review_request|booking_confirm|...
  recipient_hash TEXT,
  delivered     BOOLEAN
);

CREATE TABLE reviews (
  id            UUID PRIMARY KEY,
  client_id     UUID REFERENCES clients(id),
  ts            TIMESTAMPTZ,
  channel       TEXT CHECK (channel IN ('google','trustpilot')),
  requested     BOOLEAN DEFAULT false,
  received      BOOLEAN DEFAULT false,
  rating        INTEGER,
  text          TEXT,
  reviewer_name TEXT,
  external_url  TEXT
);

CREATE TABLE bookings (
  id              UUID PRIMARY KEY,
  client_id       UUID REFERENCES clients(id),
  ts              TIMESTAMPTZ,
  source          TEXT,  -- ai_receptionist|web_form|manual
  calcom_event_id TEXT
);

CREATE TABLE weekly_snapshots (
  client_id     UUID REFERENCES clients(id),
  week_start    DATE,
  json_metrics  JSONB,
  PRIMARY KEY (client_id, week_start)
);

CREATE INDEX idx_calls_client_ts ON calls(client_id, ts DESC);
CREATE INDEX idx_reviews_client_ts ON reviews(client_id, ts DESC);
CREATE INDEX idx_bookings_client_ts ON bookings(client_id, ts DESC);
```

## Astro page structure

```
apps/marketing-site/src/pages/r/[slug].astro
```

Pseudo:

```astro
---
import { getDashboardData } from '../../lib/dashboard';
const { slug } = Astro.params;
const data = await getDashboardData(slug); // edge fetch from n8n /api/dashboard/:slug
if (!data) return Astro.redirect('/404');
---

<Layout title={`${data.client.name} — Klantkraan dashboard`}>
  <Hero client={data.client} week={data.week} />
  <StatGrid stats={data.stats} />
  <CallList calls={data.recent_calls} />
  <ReviewWall reviews={data.latest_reviews} />
  <ContactCta whatsapp={data.client.support_whatsapp} />
</Layout>
```

## API endpoint (n8n)

`GET /api/dashboard/:slug` → SELECT from Postgres → compute weekly aggregates → return JSON.

Cache: Cloudflare KV for 5 minutes per slug to reduce DB hits.

## Weekly email (separate from dashboard view)

Every Monday 08:00 a PNG snapshot of the dashboard is generated by n8n (using `playwright` to screenshot the URL) and emailed to the owner via Resend. Email body includes top-3 calls and total stats.
