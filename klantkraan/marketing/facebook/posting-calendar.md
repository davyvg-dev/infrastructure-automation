# Facebook-groepen posting-calendar

> **Methode: handmatig plaatsen via je eigen account.** Geen bots (Groups API dood sinds
> april 2024). De `schedule.mjs` CLI vertelt je wat er deze week aan de beurt is; jij plakt
> het zelf in de juiste groep uit `groups.md`. Cadans: **2x/week, di + do**.

## Cadans + ratio

- 2 posts per week (dinsdag + donderdag), rustig opbouwen.
- **Minstens 4 value-posts : 1 promo-post.** Promo (fb-006) alleen in promo-toegestane groepen.
- Niet dezelfde draft op dezelfde dag naar meerdere groepen — varieer en spreid.
