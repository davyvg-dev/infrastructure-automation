# Klantkraan Synthflow Prompt Template (NL)

Empty-shell template consumed by the `infra/n8n/client-onboarding.json` workflow.
The workflow renders this file with `mustache`-style `{{placeholder}}` substitution and writes the result to `nl/<vertical>.<client_id>.rendered.md` before the call to the Synthflow API.

Do not edit this file to add per-client content. Per-client overrides go into the FAQ overlay (`<vertical>-faq.{client_id}.md`).

## Rendering rules

- Missing required placeholder → workflow fails fast, no deploy.
- Missing optional placeholder → substituted with the `Default` column value.
- All `number` placeholders rendered with `€` prefix and Dutch decimal comma (`€65,00`).
- All boolean placeholders evaluated for `{{#if}}` / `{{^if}}` blocks; literal substitution is forbidden in this template.
- Output written to `nl/<vertical>.<client_id>.rendered.md`; SHA-256 hash logged to `compliance_audits` table per call.

## Versioning policy

- Template changes bump the file's semver in the front-matter (when added) and require a coupled bump of every `<vertical>.vN.md` that consumes it.
- Once a `.rendered.md` is shipped to a Synthflow agent in production, its hash is immutable; a fix means a new version, never an in-place edit.
