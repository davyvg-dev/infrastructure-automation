# Klantkraan

Productized AI-receptionist + missed-call-back + review-automation for Dutch tradesmen (loodgieters + dakdekkers primary). Operates as a `handelsnaam` under T4 Software Consulting; migrates to a Holding-BV / Werk-BV structure at ~€8k MRR.

This directory is the single source of truth for strategy, sales, delivery, legal, content, outbound, finance, tech, brand and operations. All documents are versioned in git — every decision lives here, no Notion/Drive sprawl.
